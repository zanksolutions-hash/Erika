# Site Erika — Psychologue du travail

Version statique sans module de prise de rendez-vous.

## Fichiers
- `index.html` : contenu du site
- `style.css` : design
- `app.js` : menu mobile

## Publication avec GitHub Pages
Cette version ne contient aucun serveur, aucune base de données et aucun backend.
Elle peut donc être publiée directement avec GitHub Pages.

### Étapes
1. Créer un dépôt GitHub.
2. Envoyer `index.html`, `style.css` et `app.js`.
3. Ouvrir `Settings`.
4. Ouvrir `Pages`.
5. Dans `Build and deployment`, choisir :
   - Source : Deploy from a branch
   - Branch : main
   - Folder : / (root)
6. Enregistrer.
7. GitHub fournira ensuite l’adresse publique du site.

## À compléter avant publication
- Numéro de téléphone
- Adresse e-mail
- Éventuelle photo professionnelle
- Mentions légales
- Politique de confidentialité si nécessaire
- Vérification finale du contenu par la psychologue
